## 📦 Installation (2 Minuten!)

### Schritt 1: Plugin hochladen

1. Öffnen Sie: **www.caffejulia.ch/wp-admin**
2. Gehen Sie zu: **Plugins** → **Installieren**
3. Klicken Sie: **Plugin hochladen**
4. Wählen Sie: **caffe-julia-tracker-pro-v5.zip** (27 KB)
5. Klicken Sie: **Jetzt installieren**
6. Klicken Sie: **Plugin aktivieren**

✅ **Plugin ist installiert!**

---

### Schritt 2: Tracker-Seite erstellen

1. Gehen Sie zu: **Seiten** → **Erstellen**
2. Titel eingeben: **"Tracker"** (oder beliebig)
3. Im Textfeld einfügen:
   ```
   [caffe_tracker]
   ```
4. Klicken Sie: **Veröffentlichen**

✅ **Tracker-Seite ist fertig!**

---

### Schritt 3: Fertig! 🎉

**Öffnen Sie die Seite:**
- Am Computer: Ihre WordPress-Seite mit dem Tracker
- Am iPhone: Gleiche URL - funktioniert perfekt!

**Alles funktioniert wie vorher!**

- Prüfen Sie: Plugin aktiviert?

- Prüfen Sie: Sind Events vorhanden?
