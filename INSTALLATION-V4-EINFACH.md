## 🚀 Installation (2 Minuten)

### Schritt 1: Plugin hochladen

1. Öffnen Sie: **www.caffejulia.ch/wp-admin**
2. Klicken Sie links auf: **Plugins** → **Installieren**
3. Klicken Sie oben auf: **Plugin hochladen**
4. Klicken Sie auf: **Datei auswählen**
5. Wählen Sie: **caffe-julia-events-v4.zip**
6. Klicken Sie auf: **Jetzt installieren**
7. Warten Sie 5 Sekunden...
8. Klicken Sie auf: **Plugin aktivieren**

### Schritt 2: Fertig! 🎉

**Das war's!**

Im WordPress-Menü links sehen Sie jetzt:
**"Caffe Events"** ☕

---

## 🎯 Erste Schritte

### Erstes Event hinzufügen

1. Klicken Sie im Menü auf: **Caffe Events** → **Neues Event**

2. Füllen Sie das Formular aus:
   - **Event Name:** z.B. "Hochzeit Müller"
   - **Datum:** Datum auswählen
   - **Zeit:** Start- und End-Zeit ODER "Ganztägig" ankreuzen

3. **Kaffeemühlen aktivieren:**
   - Klicken Sie auf das Häkchen bei "Mühle 1" (oder 2, 3, 4)
   - Geben Sie Start-Stand ein (z.B. 1000)
   - Geben Sie End-Stand ein (z.B. 1150)
   - Differenz wird automatisch angezeigt (150 Kaffees)

4. **Milch-Verbrauch:**
   - Geben Sie Liter ein (z.B. 5.5)

5. Klicken Sie auf: **Event speichern**

✅ **Fertig!** Ihr erstes Event ist gespeichert.

---

### Events ansehen

1. Klicken Sie im Menü auf: **Caffe Events**

Sie sehen jetzt:
- ✅ Tabelle mit allen Events
- ✅ Datum, Zeit, Arbeitszeit
- ✅ Kaffeemühlen-Zählerstände
- ✅ Total Kaffees
- ✅ Milch-Verbrauch
- ✅ **Gesamt-Summe** unten in der Tabelle

---

### Excel exportieren

1. Gehen Sie zu: **Caffe Events**

2. Klicken Sie oben rechts auf: **📥 Excel Download (X Events)**

3. Datei wird heruntergeladen: `caffe-julia-events-2024-10-24.csv`

4. **Öffnen Sie die Datei:**
   - Doppelklick → Öffnet direkt in Excel
   - Oder: Excel → Öffnen → Datei auswählen

✅ **Fertig!** Alle Events in Excel.

---

## 📊 Was ist in der Excel-Datei?

**Spalten:**

| Spalte | Inhalt |
|--------|--------|
| Event Name | Name des Events |
| Datum | TT.MM.JJJJ |
| Ganztägig | Ja/Nein |
| Start-Zeit | HH:MM |
| End-Zeit | HH:MM |
| Arbeitszeit (h) | Automatisch berechnet |
| Mühle 1 Start | Zählerstand Anfang |
| Mühle 1 Ende | Zählerstand Ende |
| Mühle 1 Differenz | Anzahl Kaffees |
| Mühle 2-4 | Gleiche Struktur |
| Total Kaffees | Summe aller Mühlen |
| Milch (Liter) | Verbrauch |

**Format:** CSV mit Semikolon (`;`) - öffnet direkt in Excel

## ❓ Häufige Fragen

### Muss ich FTP benutzen?
**Nein!** Alles läuft in WordPress.

### Muss ich etwas konfigurieren?
**Nein!** Funktioniert sofort nach Aktivierung.

### Wo werden die Daten gespeichert?
In Ihrer WordPress-Datenbank. Sicher und automatisch gesichert mit WordPress-Backup.

### Kann ich Events löschen?
Ja, in der Events-Liste: **Löschen** Button

### Kann ich Events bearbeiten?
In v4.0 noch nicht. Aktuell: Löschen und neu anlegen.
(Kommt in v4.1)

### Was passiert beim Deinstallieren?
Die Events bleiben in der Datenbank erhalten (Sicherheit).

### Funktioniert das auf Shared Hosting?
**Ja!** Funktioniert auf allen WordPress-Hostings.

### Brauche ich besondere Server-Rechte?
**Nein!** Normales WordPress reicht.
