# Fix für Version 5.1 - Mehrtägige Events

## 🐛 Probleme

1. **Andere Tage nicht bearbeitbar** 
2. **Mitteilungsfeld pro Tag statt pro Event**

## ✅ Lösung (Workaround bis v5.1)

### Problem 1: Andere Tage bearbeiten

**Aktuell:**
- Klicken Sie auf den Event-Namen (z.B. "Hochzeit Müller")
- Sie sehen die Übersicht mit allen Tagen
- **Klicken Sie auf den jeweiligen Tag** (z.B. "Hochzeit Müller - Tag 2")
- Jetzt können Sie diesen Tag bearbeiten!

**Navigation:**
```
Übersicht → Event-Gruppe → Einzelner Tag → Bearbeiten
```

### Problem 2: Mitteilung für gesamten Event

**Workaround:**
- Geben Sie die Mitteilung bei **Tag 1** ein
- Kopieren Sie den Text
- Gehen Sie zu Tag 2, 3, etc.
- Fügen Sie denselben Text ein

**Besser (kommt in v5.1):**
- Mitteilungsfeld wird auf Event-Gruppen-Ebene verschoben
- Gilt automatisch für alle Tage
